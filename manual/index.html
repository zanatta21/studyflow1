Documentação completa do aplicativo de organização dos estudos

Apresentação

O StudyFlow é um aplicativo Flutter para organização acadêmica. Reúne disciplinas, tarefas, provas, calendário, metas e um painel de progresso em uma única interface.

Objetivo e público-alvo

Objetivo: apresentar uma visão organizada das atividades acadêmicas.
Público-alvo: estudantes do ensino médio, técnico e superior.

Módulos do aplicativo

MóduloFuncionalidades
ProgressoDashboard com contadores, barras de progresso, próximas provas e tarefas pendentes
DisciplinasCRUD completo (nome, professor, descrição, cor)
TarefasCRUD com disciplina vinculada, prioridade, data de entrega e status concluído
ProvasCRUD com data, local, nota, observações e status realizada
CalendárioVisualização mensal com marcadores de tarefas e provas; lista do dia selecionado
MetasCRUD com valor-alvo, unidade (horas/tarefas/provas/páginas), prazo e registro de progresso

Login e cadastro

Autenticação via Firebase Auth (e-mail/senha).
AuthService.login() e AuthService.register().
Validação de campos e mensagens de erro amigáveis.

Tecnologias

  • Flutter + Dart
  • Firebase Authentication + Cloud Firestore
  • Provider (estado)
  • table_calendar, percent_indicator, google_fonts, intl

Passo a passo para instalação

  1. git clone ... && cd studyflow
  2. flutter create . --project-name studyflow
  3. flutter pub get
  4. Firebase Console → Authentication (Email/Senha) + Firestore
  5. Colocar google-services.json em android/app/
  6. flutter run

Estrutura do banco de dados

subjects

name, professor, description, color, userId, createdAt

tasks

title, description, subjectId, subjectName, dueDate, completed, priority (baixa/media/alta), userId, createdAt

exams

title, subjectId, subjectName, date, location, notes, grade, completed, userId, createdAt

goals

title, description, targetValue, currentValue, unit (horas/tarefas/provas/páginas), deadline, completed, userId, createdAt

Como cadastrar, editar e excluir

Tudo passa pelo DataService:

  • createSubject / updateSubject / deleteSubject
  • createTask / updateTask / deleteTask / toggleTask
  • createExam / updateExam / deleteExam
  • createGoal / updateGoal / deleteGoal

Como alterar cores

Arquivo lib/theme/app_theme.dart — constantes primary, secondary, etc.

Como trocar o logo

  1. Coloque a imagem em assets/images/logo.png
  2. Substitua o Icon(Icons.menu_book_rounded) por Image.asset(...) no Splash e Login

Como alterar o nome do app

  • main.dart → title
  • Textos nas telas e AppBar
  • AndroidManifest.xml (android:label)

Como adicionar uma nova tela

  1. Crie em lib/screens/
  2. Adicione no array _pages e no BottomNavigationBar de main_shell.dart

Como adicionar um campo no banco

  1. Atualize o model (fromFirestore, toMap, copyWith)
  2. Atualize o formulário da tela correspondente
  3. Atualize a listagem/card se for exibir

Como gerar nova versão

Atualize version no pubspec.yaml e rode flutter build apk --release.

Solução de problemas comuns

ProblemaSolução
Firebase não inicializadoVerificar Firebase.initializeApp() e google-services.json
Erro de índice no FirestoreCriar o índice composto pelo link que aparece no log
Calendário sem locale pt_BRAdicionar initializeDateFormatting('pt_BR') no main se necessário
Lista vazia após criarVerificar regras do Firestore e se userId está correto
App travaflutter clean && flutter pub get
